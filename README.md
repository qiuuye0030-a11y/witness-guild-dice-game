# 见证者公会 · 互动式骰子文字游戏

当前源码：**10.06，战斗V14**。单人离线养成与斗魂游戏，提供经典深靛、晨曦朝阳两种主题。

10.06把冻结的V14战斗修正合入模块化源码：自身强化完整作用于施法者，护盾按来源分层、外层先承伤，生命与精神防护分别结算；战斗预测与考官决策共用同一实现。新增4项隐藏成就，达成后才显示，并以“公会见证”卡片呈现；赞助入口口令为 `witness`；使用独立的10.06自动存档槽，可读取旧版本地存档。

长期强化策略完成一轮研究：24秒窗口、最多两次后续行动的候选在对照中退步，未纳入成品，正式版本保留冻结V14策略；暗牧与两位辅助的低胜率问题仍在研究，本版不宣称已完成全面数值平衡。

## 游玩与构建

下载对应发布附件后，用浏览器打开HTML，可离线运行。源码也可以直接构建：

```text
npm run build
```

需要Node.js22及Python3。构建只用Python标准库，生成根目录的两份10.06 HTML与分享包。

## 源码入口

- 骰子、事件、旅程与战斗模块：`骰子系统/systems/`。
- 目录职责、编辑源与生成入口：[系统说明](骰子系统/systems/README.md)。
- 当前168事件、10任务链：编辑`骰子系统/story-source-1003.json`，再运行同目录`_sync_story_data.py`。
- 页面及主题：`骰子系统/campaign-ui.js`、CSS与`晨曦城_朝阳前端组件/`。
- 隐藏成就实现：`骰子系统/achievements.js`；含剧透的条件清单与开发记录不进入任何发布包。
- 冻结对照源：`骰子系统/fixtures/v13-baseline/`只作V13历史对照，不再用于判断10.06行为；`见证者公会_V14_完整交接版_2026-10-15/`是精简的V14参考目录，供配对检查使用。

顶层core.js、campaign.js、campaign-events.js及战斗引擎包由模块生成，避免直接编辑。不要追加prototype覆盖补丁。

## 验证

```text
npm test
```

无需安装npm依赖。覆盖结构约束、隐藏成就边界、V13/V14读档集成、旧规则回归，以及与冻结V14的42场、1791个逐步快照配对对照。

构建后在“骰子系统”目录运行：

```text
python -X utf8 verify-package-1006.py
```

浏览器检查另需Playwright、PNGJS及本机浏览器，参见[开发约定](CONTRIBUTING.md)。GitHub自动检查先构建两个主题，再运行回归，最后校验封装；远端执行状态以Actions实际结果为准。
