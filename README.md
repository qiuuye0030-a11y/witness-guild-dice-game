# 见证者公会 · 互动式骰子文字游戏

当前源码：**10.05，战斗V13**。单人离线养成与斗魂游戏，提供经典深靛、晨曦朝阳两种主题。

本次整理源码结构，版本号和玩法不变。原版保留作对照，逐步比较骰子、培养和战斗快照；没有混入后续V14规则。

## 游玩与构建

下载对应发布附件后，用浏览器打开HTML，可离线运行。源码也可以直接构建：

```text
npm run build
```

需要Node.js22及Python3。构建只用Python标准库，生成根目录的两份10.05 HTML与分享包。

## 源码入口

- 骰子、事件、旅程与战斗模块：`骰子系统/systems/`。
- 目录职责、编辑源与生成入口：[系统说明](骰子系统/systems/README.md)。
- 当前168事件、10任务链：编辑`骰子系统/story-source-1003.json`，再运行同目录`_sync_story_data.py`。
- 页面及主题：`骰子系统/campaign-ui.js`、CSS与`晨曦城_朝阳前端组件/`。
- 新旧对照夹具：`骰子系统/fixtures/v13-baseline/`，只用于测试，不进入游戏成品。

顶层core.js、campaign.js、campaign-events.js及战斗引擎包由模块生成，避免直接编辑。不要追加prototype覆盖补丁。

## 验证

```text
npm test
```

无需安装npm依赖。覆盖结构约束、数值规则、会员机制、168事件/10任务链、4,000次骰点、960组魂技、210场逐步战斗及200条逐步培养对照。

构建后在“骰子系统”目录运行：

```text
python -X utf8 verify-package-1005.py
node simulate-1005.cjs
```

第二项是较长的1,000条培养/420场对战联测。浏览器检查另需Playwright、PNGJS及本机浏览器，参见[开发约定](CONTRIBUTING.md)。GitHub自动检查配置包含基础回归、构建和包验证；远端执行状态以Actions实际结果为准。
