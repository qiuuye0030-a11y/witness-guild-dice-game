# 见证者公会 · 互动式骰子文字游戏

当前源码：**v12.01（战斗规则V17、成长规则10081、讨伐与魂骨版）**。单人离线养成与斗魂游戏，提供经典深靛、晨曦朝阳两种主题，两主题采用相同规则。

v12 在 v11 基础上加入讨伐战与魂骨装备：讨伐改为无时限、同一次邀请最多进战 3 次、连续 10 秒全队无力行动判中止；胜利需魂兽真实退场且仍有友方存活才给环骨；万年骨特性池仍待补充，界面显示“特性待装配”。v12.01 以 v12 为基线独立修订：新增统一效果视图（实际层数与来源期限直接显示在增益／减益标签和“战斗状态”里）、修复巨蛙迟缓免疫被 `statDownA`、困阵等入口绕过、程良·六库仙贼每回合回复最大生命与魂力各 5%，并修正盗气与吞噬回魂的越界结算。

## 游玩与构建

发布附件里的两个主题 HTML 全部资源内置，浏览器直接打开即可离线游玩。源码构建在仓库根目录：

```text
npm run build        # python 骰子系统/_build_v12.py，生成两份主题HTML与分享包
```

需要 Node.js 22 与 Python 3.10+，只用标准库，无 npm 依赖。构建会在仓库根目录生成 `见证者公会_v12.01版_*.html` 与 `见证者公会_v12.01版_双前端分享包.zip`。

## 源码入口

- 战斗、成长、事件、骰子模块：`骰子系统/systems/`；讨伐与魂骨规则：`骰子系统/systems/v12/`（`v12/ui.js`、`effect-view.js`）；独立讨伐模块包：`systems/v12/modules/`（自带 `README.md`、数据与 188 项校验器）。
- 故事与事件：编辑 `骰子系统/story-source-1003.json`，再运行同目录 `_sync_story_data.py`。
- 武魂精简：`武魂十档候选库.json` 为构建输入，`武魂删留映射.csv`／`精简武魂总表.csv` 记录删留与档位。
- 冻结对照：`骰子系统/fixtures/`（`1006-reference/`、`1007-reference/`、`1008-before-rollback/`、`v13-baseline/`、`v11-before-matrix/`），只用于对照，不进入游戏成品。

顶层 `core.js`、`campaign.js`、`campaign-events.js`、`systems/events/legacy-data.js` 与战斗引擎包由 `_build_v12_modules.py`、`_sync_systems.py`、`_sync_v13.py` 生成，不要直接编辑，也不要追加 prototype 覆盖补丁。

## 验证

在仓库根目录：

```text
npm test             # node 骰子系统/tools/verify-v12-package.cjs，核对主题HTML、脚本编译与构建清单
npm run regression   # python 骰子系统/tools/verify-v12-release.py，跑 9 组回归
```

构建必须先于检查：两项检查都读取生成后的主题 HTML 与 `v12.01版双前端分享/构建清单.json`。`npm run regression` 覆盖 12 项 v12.01 专项、31 项 v12 核心、9 项界面组件、188 项独立模块，以及旧战斗、伤疤女、成长、成就与 60 条完整成长旅程；逐项记录写入 `骰子系统/output/v12/`。

界面检查为离线组件与脚本检查，**尚未完成真实浏览器目视验收**；来件战报的新规则重放只是单场功能例证，不作为整体胜率或平衡结论。详见 [v12.01 更新说明](v12.01_更新说明.md) 与 [战报检视](v12.01_战报检视.md)。

GitHub 自动检查按“构建 → 封装核对 → 9 组回归”执行，远端结果以 Actions 为准。
