## 属性口径

魂技继承所属武魂的全部属性，复合属性完整保留；没有属性时明确写“无”。物理、能量、精神继续作为伤害通道，不充当属性名。攻击、控制、防御、强化、治疗等魂技都遵循相同标签规则。

统一字段：

- `attribute`：显示字符串，例如“火”“木／冰”“无”。
- `attributeTags` / `elements`：供判断使用的属性数组，例如 `["木","冰"]`；无属性为 `["无"]`。
- `element`：兼容单字段读取的显示别名；复合时仍完整显示，不擅自取其中之一。
- `attributeRulesVersion:1`：标签版本。

明确标为“无属性”的武魂不会因拥有空间等机制词被自动改成元素属性。例如当前程良魔方的源数据分类为无属性，故魂技显示“无”；空间机制仍单独保留。

本轮只增加属性标签及传递接口，**没有新增属性克制倍率、抗性或免疫规则**。魂兽原有冰免疫等被动仍须由其专属执行器读取标签后实现，不能靠标签字段自行产生效果。

## 接入入口

```js
const api = modules.battle.skillAttributes;
const tagged = api.tagSkill(skill, resolvedSoul);
const refreshedCharacter = api.tagCharacterSkills(character, resolvedSoul);
const refreshedUnit = api.tagUnitSkills(unit);
```

`resolvedSoul` 必须是解析后的武魂对象，不能只传武魂ID。刷新入口只补/更新标签，保留魂技名称、效果、类别、费用、数值和生成种子；人物成长不变。人物已吸收环、预留九环与待处理九环一并刷新，魂骨特性不被当作武魂魂技改写。

本包 `modules.bridge.makeSkill`、注入规则后的 `modules.bridge.makeSkill`、NPC转换与讨伐队伍接口均会自动补标签。主游戏若直接调用原来的 `WitnessRules.makeSkill`，仍须在接入层调用 `tagSkill`，或改走本包桥接入口；不能认为本轮已经改写旧游戏的全局规则。
