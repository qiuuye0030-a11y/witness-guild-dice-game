# 10.08独立挑战模块

挑战代码仅在本目录。`battle.js`包含会长档案、九技/魂骨和四被动；`state.js`负责结局资格、场次、五次失败与本机账本；`ui.js`负责目录、确认弹窗与结算；`challenge.css`负责挑战界面。

会长不加入`WitnessTemplates`。只有显式创建`challengeId: guildmaster_xuejidong`的结局后挑战才初始化此档案。普通雪寂冬考官仍使用六技库，原设97级和挑战95级分别保留。

共用引擎通过`systems/battle/modern.js`中的明确事件调用本模块；Battle/Campaign各一次装配，无后加载原型覆盖链。构建脚本显式打包本目录的状态与界面文件。

`modern.js`是整个10.08共享的战斗规则源，包含追势、连击和免伤，不能与挑战被动混为一谈。隔离模块压缩包附共用接入点说明，不代表能独立替代整套战斗引擎。

五次额度指同一人物、所有目录共享的累计五次失败。开始时保留场次，取消不扣，胜利不扣，认输算失败，刷新恢复同场。成功结局导入可解锁；失败结局不解锁。原会徽、考核次数、培养数值不因挑战改变；会长挑战胜利可解锁独立隐藏见证。

九环第二技能仍未知，不编造。头部魂骨是独立能力，不是第十魂技。当前没有空间/距离模拟，范围与飞行仅作已说明的简化。

旧v1账本沿用原键与原失败数；旧档3次失败的exhausted会重算为false，另余2次。
